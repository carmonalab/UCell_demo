This notebook reproduces results from pyUCell with the R version of UCell. We will use a test object from scanpy, also used in pyUCell’s demo.

library(UCell)
library(reticulate)
library(zellkonverter)
library(Seurat)
library(ggplot2)

Download anndata object from scanpy. This requires “reticulate” to run python from within R. Alternatively, you may download and store the pbmc3k.h5ad from a python session.

do_download <- FALSE

if (do_download) {
  use_python("/usr/bin/python3", required = TRUE)
  sc <- import("scanpy")
  
  adata <- sc$datasets$pbmc3k()
  adata$write("pbmc3k.h5ad")
}

Read object into R. For conversion, we will use zellkoverter; first converts an “.h5ad” object to “sce” format, then we can convert from “sce” to “Seurat”. Conversions between R and python objects are known to be clunky.

sce <- readH5AD("pbmc3k.h5ad")
pbmc <- as.Seurat(sce, counts="X", data=NULL)
